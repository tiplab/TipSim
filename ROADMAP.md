# TipSim Roadmap

TipSim will keep evolving around **more sensors, lower integration cost, more robot platforms, and a more complete simulation data toolchain**.

| Stage | Planned Work |
| --- | --- |
| **Current** | MuJoCo plugin integration; Loong / Universa support (both depend only on MuJoCo, no third-party runtime libraries); Python / C++ samples; dexterous-hand and UR5e scenes |
| **Next** | Further simplify installation and dependency checks; automated runtime integrity checks; a unified sample entry point; more gripper, dexterous-hand, and robot models |
| **Sensor Expansion** | Bring in more Tip tactile products, including the Insight series; more standardized sensor assets and config templates |
| **Platform Expansion** | Push forward support for simulation platforms such as Isaac Sim, and gradually unify the tactile data interface across platforms |
| **Data & Benchmark** | Add batch simulation, data collection, and representative robot-manipulation-task samples, working toward a reusable tactile simulation benchmark |
| **SDK Experience** | A more convenient Python install path, version management, cross-distro binary releases, and a stable interface, to lower integration and deployment cost |

> This roadmap reflects current direction; specific features, versions, and release timing may change as development progresses.
